Актуальная ссылка на VPN-подписку

Здесь появится свежая ссылка из Telegram-канала после первого запуска обновления.

Запусти один раз вручную: закладка Actions → Update VPN subscription → кнопка Run workflow. Через минуту эта страница автоматически заменится: на ней будут ссылка с кнопкой «Скопировать», число серверов в подписке и история смен ссылок.

Если ты ещё не вписал канал — сделай это: Settings → Secrets and variables → Actions → Variables → TG_CHANNEL.
